PhotoMeasure – Self-Test / ทดสอบระบบด้วยตัวเอง

Press “Run all tests”. / กด “เริ่มทดสอบ”
Runs completely offline. It measures 3 known photos with a fixed program and compares every value with the reference results (golden values), then builds the 4 report types and checks the Camera Bridge. Run it before and after every change, and before releasing a new version. All tests must be PASS.
ทำงานได้โดยไม่ต้องใช้อินเทอร์เน็ต: วัดภาพตัวอย่าง 3 ภาพด้วยโปรแกรมที่กำหนดไว้ แล้วเทียบทุกค่ากับผลอ้างอิง สร้างรายงาน 4 แบบ และตรวจ Camera Bridge ให้รันก่อนและหลังแก้ไขทุกครั้ง และก่อนนำเวอร์ชันใหม่ไปใช้งานจริง ทุกข้อต้อง PASS
