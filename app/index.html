How it is used

Programs with reference mode Fixed calibration (station, no REF holes) take the scale (mm per pixel) from the saved calibration of their station (camera serial, or "photos from files"). Programs with REF circles calibrate on every photo and do not need it, but the plate check is still a good daily check of focus and camera height.

1. Put the plate where the part is measured, in focus.
2. Choose the plate type and enter the dot pitch or the gauge diameter.
3. Grab plate (camera) or Load plate image.
4. Admin / engineer: Save calibration. Daily: Check against saved.

Use the backup to move users and programs to another PC, or from the file version (index.html) to the Camera Bridge version (http://127.0.0.1:5090): each keeps its own data.

Users and passwords are kept on this PC (in this browser). Passwords are stored as salted SHA-256 hashes. The roles keep normal users to their work; they are not protection against someone who opens the browser's developer tools.

Train a reader

Trained readers

How it works

  1. Part program: draw a text (OCR) area on the master, set the format (e.g. AAA9).
  2. Measure: press 💾 Save characters (or tick "Save characters of every measured photo"). Each character becomes a 32×32 image, labelled from the reading.
  3. Here: check the labels (wrong labels teach wrong answers), delete bad crops. Aim for 50+ images per character from several days.
  4. Train: 70 % of the images teach, 15 % check progress (validation), 15 % are the final test.
  5. Use: in the readers table choose the text element, or in the program set Reader of the text element. Save the program to the library.
